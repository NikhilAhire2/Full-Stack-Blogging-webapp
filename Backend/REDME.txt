What is Data URI?

A Data URI is a way to embed file data directly inside a URL as text (Base64 encoded)

Basically is help store data(images,video) base64 in database
it also helps to show preview of the image without uplod in database
ex {
  "image": "data:image/jpeg;base64,/9j/4AAQSk..."
